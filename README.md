🎯 Interview Assistant

📌 Description

Interview Assistant ek web-based application hai jo users ko interview preparation me help karta hai. Isme users interview questions explore kar sakte hain aur apne experiences share kar sakte hain.

---

🚀 Features

- 📋 Interview questions collection
- ✍️ Experience sharing system
- 🔐 User authentication (Login / Signup)
- 📊 Organized and easy-to-use interface

---

🛠️ Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MongoDB

---

⚙️ Installation & Setup

1. Clone the repository:

git clone https://github.com/mpal03708-dot/Interview-Assistant.git

2. Move into project folder:

cd Interview-Assistant

3. Install dependencies:

npm install

4. Create a ".env" file and add:

MONGO_URI=your_mongodb_connection_string
PORT=5000

5. Start the server:

npm start
